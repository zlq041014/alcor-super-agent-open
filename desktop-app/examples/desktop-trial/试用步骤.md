# 星引 Windows 独立试用

将候选包解压到 D 盘的可写目录，运行包内的 `启动独立试用.cmd`。它使用同一目录下的 `trial-data`，不会打开日常星引的账本。样例文件可修改，原始 ZIP 保留初始内容。

1. 在设置中选择 DSH 或 Codex 托管执行，保存实际可用的 API 端点、协议及模型，并通过独立密钥窗口录入配置。连接测试成功才继续。如果选择 Codex，需要在隔离环境按实际供应商另行配置原生凭据。样例不需要 DSH 原桌面桥。
2. 在「项目」绑定本文件旁的「样例甲」和「样例乙」。按各目录「说明」提交工作，核对写入范围。样例甲检查 `result.txt`；样例乙检查答复来源和原文件是否仍保持原样。
3. 在有足够时间的样例工作中试一次暂停、补充要求或继续。核对外壳、Hub 和原生端显示的请求接收、终止与结果状态，特别注意“待核对”尚不代表已停止或已保存。
4. 输入一段草稿，完整退出并再次运行独立试用入口。核对草稿、项目、已交付文件和工作状态。若尝试备份和恢复，请在这套独立试用数据内操作。

如遇问题，请记录候选包来源、操作、预期和实际结果。密钥、认证头和真实任务内容不要附在反馈中。候选包用于实际试用，日用版、原数据与备份保持原位。
