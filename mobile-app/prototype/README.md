# 手机总管首版 · 网页交互原型

2026-11-24 · 按[首版体验目标](../../docs/mobile-manager-v1.md#首版体验目标)做的可点击设计稿。用于对齐交互与视觉，**不是实现，也不是验收证据**：页面不连接 DeepSeek、Hub、Codex 或 DSH；搜索来源是 `*.example` 示例域名；所有电脑回执都由右侧「模拟证据」按钮产生。

## 打开方式

- 直接双击 `index.html`；或 `node tools/serve.cjs`（默认 `http://127.0.0.1:5178/`，只监听本机）。本机没有全局 Node 时，可用桌面工程的 Electron 代跑：`$env:ELECTRON_RUN_AS_NODE='1'; ..\..\desktop-app\node_modules\electron\dist\electron.exe tools\serve.cjs`。
- 宽屏（≥1180px）显示三栏：左侧场景导览，中间手机，右侧本屏要点、模拟环境和模拟证据。窄屏只显示手机画面，右下「场景」按钮切换场景；模拟证据需要宽屏。
- `index.html?s=s7` 可直接打开某个场景。

## 场景与对应目标

| 目标 | 场景 | 要看的点 |
| --- | --- | --- |
| 1 打开就能说事 | s1 打开就能说事 | 首屏即对话；「继续上次讨论」「DSH 在等你回答」就地打开；无事项不摆空面板 |
| | s2 首次使用只补一步 | 缺 DeepSeek 配置只引导这一步，已输入的话保存后接着发 |
| | s3 一句话接上昨天的讨论 | 唯一匹配直接打开，说明依据记录与同步时间；未同步正文标缺口 |
| | s4 说法有歧义 | 只给 3 个候选，含来源、项目、所在电脑；同名项目按设备区分 |
| | s8 自己找会话 | 项目 / 最近 / 分类三视图共用总管索引；最近按使用排序 |
| 2 电脑全关也有价值 | s5 电脑全关也能办事 | 搜索带来源与检索时间；起草可复制；选定文案记为决定但不派工 |
| | s9 手机也断网 | 能看记录、存草稿；不显示新回答；联网后由用户点发送 |
| 3 总管衔接电脑 | s6 从讨论转为执行 | 交接卡写明做什么、发往哪、原会话、权限、验收；点「交给电脑」才算授权 |
| 4 状态要真 | s7 等待如实显示 | 已记下 → 电脑已收到 → 执行中 → 待验收 → 已完成，各自需要对应证据；回执丢失显示「送达待核对」；重放事件去重 |
| | s10 决定在两处被改 | 两版都保留，只选冲突项 |

状态文案与证据的对应沿用设计文档[「让等待可理解」](../../docs/mobile-manager-v1.md#让等待可理解)一节；原型增加了「执行失败」「已撤销，未派发」两种结局的样式。

## 视觉与图标

- 色彩沿用桌面 0.2.0 的品牌紫 `#6657d9`；状态色：待发灰、已收到蓝、待核对/执行中琥珀、待验收紫、已完成绿、失败红。支持深色（右侧「深色」开关）与「减弱动画」。
- App 图标与特殊图标在 2026-11-24 用 `gpt-image-2.5-sunburst` 生成，共 13 张。原图和处理后的构建素材均随源码保存。
  - 主图标 `assets/app-icon-*.png`：亮白引导星 + 琥珀伴星（Alcor 是北斗开阳旁的伴星），弧线表示手机与电脑相连。备选 `app-icon-b-*`：对话气泡 + 星。
  - 特殊图标（256px 透明底）：`avatar` 总管、`phone-assistant` 手机助手、`exec-codex` / `exec-dsh` 执行端（原创几何图形，不是对应产品的官方标志）、`handoff` 交接、`decision` 决定、`receipt` 回执、`search-source` 搜索来源、`computer-asleep` 电脑离线、`offline-phone` 手机断网、`find-sessions` 找会话。
  - 小尺寸界面图标（发送、返回等）用内联 SVG，不用生图。
- 重新生成：`art/generate.ps1 [-Only 名称] [-Force]`（会消耗生图额度），再运行 `art/postprocess.ps1` 裁透明边并输出到 `assets/`。原图保存在 `art/raw/`；48px 和 512px 启动图标是可重建的本地输出，Android 和原型使用随仓库保存的 192px 图标。

## 自检

`tools/shoot.cjs` 用 Playwright + 本机 Edge 依次走完各场景的关键交互，截图写入 `evidence/`，并收集页面报错。沙箱里需把 `TEMP`/`TMP` 指到项目内目录：

```powershell
$env:TEMP='D:\projects\alcor-super-agent\.dev\tmp'; $env:TMP=$env:TEMP; $env:ELECTRON_RUN_AS_NODE='1'
..\..\desktop-app\node_modules\electron\dist\electron.exe tools\shoot.cjs
```

2026-11-24 结果：30 张截图生成，无页面报错。只证明原型脚本可走通，不代表任何跨端能力已实现。
