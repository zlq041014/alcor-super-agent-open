# 手机个人助手 · 网页设计原型

2026-11-25 · 按[手机个人助手](../../docs/mobile-assistant-v2.md)的范围做的可点击设计稿：首版已交付的界面加上 M1～M7 的界面，含小引。

它只用来对齐交互与视觉，**不是实现，也不是验收证据**：

- 页面不连接 DeepSeek、Hub、Codex 或 DSH。
- 对话、搜索来源、店名、天气和用量都是示例。来源用 `*.example` 域名，店名标了「示例」。
- 电脑和执行端的回执由右侧「模拟证据」的按钮产生。

首版的 10 个场景原型仍在 [../prototype](../prototype/README.md)，作为已交付首版的设计基线保留，没有改动。

## 打开方式

- 直接双击 `index.html`。
- 或起一个只监听本机的静态服务：`node tools/serve.cjs`，默认 `http://127.0.0.1:5179/`。本机没有全局 Node 时用桌面工程的 Electron 代跑：

  ```powershell
  $env:ELECTRON_RUN_AS_NODE='1'
  ..\..\desktop-app\node_modules\electron\dist\electron.exe tools\serve.cjs | Out-Host
  ```

顶部有三个视图：

| 视图 | 内容 |
| --- | --- |
| 可点击原型 | 宽屏（≥1180px）三栏：左侧场景导览，中间手机，右侧是本屏要点、模拟环境、模拟证据和小引当前的动作。 |
| 全景 | 46 个场景的初始画面缩小排开，点一张回到可点击原型。 |
| 设计规范 | 原则、四套主题的颜色、字号、状态词表、应用图标候选、特殊图标、界面小图标、小引的 15 个动作和组件。 |

窄屏只显示手机画面，右上角的「场景」按钮切换场景。

地址参数：`?s=f5` 直接打开某个场景，`&dark=1` 用深色，`?view=board` 或 `?view=spec` 直接进全景或设计规范。

## 这一版界面的做法

设计文档没有写到、由原型引入的做法记在[界面：原型与界面设计建议](../../docs/mobile-assistant-v2.md#v2-ui)，都是可以改的设计建议。要点：

- **首页只有对话和一个输入框。** 其余入口收在左侧抽屉里，右上角的铃铛是「待处理」，没有底部标签。
- **输入框有两个出口。** 右侧并排「记一笔」和发送。打了字点「记一笔」，直接存进本机收件箱，不发给模型。
- **两种模式，两种颜色。** 工作模式是主星的紫，生活模式是伴星的琥珀。在一种模式里，另一侧只亮一个圆点。
- **小引在首页头像处。** 没有消息时 2 倍大小居中，开始对话后缩成 1 倍头像。点它「戳一下」，点旁边的状态文字看每项工作的准确状态。
- **每轮答复的过程都看得见。** 工具调用收在答复上方的一行里，可以展开；来源卡片在答复下面；再下面一行是用到的记忆、估算金额、复制和导出。
- **电脑有自己的名字。** 默认显示配对时电脑报告的系统设备名；可以加一条备注，有备注显示备注，没有就显示设备名。备注在「电脑 → 这台电脑」里改。
- **状态只跟证据走。** 交接的每一步、小引的每个动作都要有对应的回执；没有就不往前显示。
- **界面上少写字。** 列表直接显示内容，图标配短标签，当前值放右侧。回执先显示状态、结果和验收，授权与完整记录可展开。同意和花费在确认前说清。设计理由放在右侧「本屏要点」。

## 场景

46 个场景，每个场景是一份预设状态，输入框里预先放好了那一场的示例。左侧导览按下表分组。

| 组 | 对应 | 场景 |
| --- | --- | --- |
| a 打开就能用 | 首版目标 1、M5.2 | a1 首页·工作模式；a2 首页·生活模式；a3 第一次打开；a4 系统入口（图标长按、小组件、分享、通知）；a5 抽屉 |
| b 记一笔 | M1 | b1 快速记一笔；b2 语音记一笔；b3 收件箱与找回；b4 笔记详情（原文一层、整理一层）；b5 把笔记用起来 |
| c 接着聊，自己动手 | M2、M3 | c1 新对话；c2 助手自己动手；c3 在对话里办小事；c4 资料不是指令；c5 长对话不断片；c6 这一轮花了多少；c7 手机也断网 |
| d 记得你 | M4 | d1 记忆；d2 人格与风格；d3 生活与工作；d4 权限；d5 应用锁与备份 |
| e 生活 | M5 | e1 提醒；e2 天气与雨天预警；e3 附近的吃和玩；e4 每日简报 |
| f 交给电脑 | 首版目标 1、3、4，M2.2、M6 | f1 一句话接上昨天的讨论；f2 说法有歧义；f3 挂到项目；f4 交接卡；f5 等待如实显示；f6 回执丢了；f7 回执与验收；f8 待处理与未读；f9 项目与 Agent 结构；f10 电脑与连接路线；f11 决定在两处被改 |
| g 成果 | M7 | g1 架构图预览；g2 PPT 大纲；g3 相册整理；g4 拍照即问 |
| h 小引与设置 | M6.4 | h1 小引；h2 设置；h3 模型与 Key；h4 用量与花费；h5 通知 |

最能说明这一版的三条线：

1. **记下 → 聊透 → 交办 → 收回。** b1 记一笔，b5 把笔记带进对话，f3 挂到项目并交给电脑，f7 验收。
2. **回执推进。** 打开 f5，在右侧「模拟证据」里依次点「LAPTOP-8F2M4C 上线，回执正常」「执行端：回合开始」「执行端：回合结束，有结果」，看首页的卡片和小引怎么变；再点卡片进去验收。换成「上线，但回执丢了」，看「送达待核对」。
3. **两种模式。** a1 和 a2 之间切换；d3 是分开放了什么的说明。

右侧「模拟环境」可以关掉手机网络、切换两台电脑的在线和路线（离线、直连、中继、隧道）、换时间段，以及让小引休眠。

## 小引

- 复用桌面端的精灵表。`art/postprocess.ps1` 把 `desktop-app/assets/pet/` 的精灵表和元数据同步到 `assets/pet/`；改动作后先重新生成桌面素材，再运行它。
- 动作与触发证据以 [desktop-pet.md](../../docs/desktop-pet.md) 为准。播哪个动作由 `js/pet.js` 的 `petBase()` 按文档里的显示顺序决定：互动 ＞ 对话 ＞ 工作状态 ＞ 常驻。
- 「送出」和「完成」是一次性动作，分别在收到「已收到」回执和你验收之后播一次。
- 生活模式下不播放工作状态。
- 没有为手机新增动作。「记下了」只是一条可撤销的提示。
- 场景 h1 是介绍页，可以逐个播放 15 个动作，也可以「演示一次派工」。

## 视觉与图标

- 四套主题（工作、生活 × 浅色、深色）由 `css/app.css` 顶部的一组设计令牌驱动。状态色与首版原型、桌宠气泡一致。
- 字体只用系统中文字体，不加载网络字体。
- 界面小图标是 `js/icons.js` 里的内联 SVG。
- 应用图标和特殊图标用本机的 `gpt-image-2.5-sunburst` 生成，2026-11-25 新生成 24 张，一次通过；另从首版原图里复用 11 张。处理后的素材在 `assets/`，共 34 张，256 px。
  - 应用图标：`app-icon-a` 是现用的；`app-icon-c`（小引）和 `app-icon-d`（从夜到晨）是候选。换不换由用户决定。
  - 特殊图标 31 张，清单和用途见「设计规范」视图。Codex 和 DSH 是原创的几何图形，不是对应产品的官方标志。
- 重新生成：`art/generate.ps1 [-Only 名称] [-Force]` 会消耗生图额度；之后运行 `art/postprocess.ps1` 裁透明边、缩放并输出到 `assets/`。清单和提示词在 `art/manifest.json`，新生成的原图在 `art/raw/`（约 25 MB）。脚本不读取也不输出任何 Key。

## 自检

两个脚本都用桌面工程的 Playwright 和本机 Edge，按上面的方式用 Electron 代跑：

```powershell
$env:ELECTRON_RUN_AS_NODE='1'; $env:TEMP='D:\projects\alcor-super-agent\.dev\tmp'; $env:TMP=$env:TEMP
..\..\desktop-app\node_modules\electron\dist\electron.exe tools\shoot.cjs | Out-Host
..\..\desktop-app\node_modules\electron\dist\electron.exe tools\walk.cjs | Out-Host
```

- `tools/shoot.cjs`：逐个打开场景截图，再走一遍主要流程（发送与流式答复、首次接入、记一笔、交接与回执推进、验收、系统入口、拍照即问），并截全景、设计规范和窄屏。
- `tools/walk.cjs`：39 条点击链，覆盖各二级页面和浮层里的开关、标签、撤销和跳转。点不到的目标和页面报错都会列出来。

截图写入 `evidence/`，不进版本库。

2026-11-25 复验：`shoot.cjs` 覆盖 46 个场景，生成 79 张截图；`walk.cjs` 39 条点击链全部通过，两个脚本均无页面报错。另在 320 px 下检查了场景入口与布局、交接授权、权限开关、回执展开和照片费用提示，并检查了 392 px 深色样例。本轮截图在本机 `evidence/compact-20261125/`。这些是原型检查结果。

2026-11-25 改设备称呼后复验：`shoot.cjs` 仍是 46 个场景、79 张截图；`walk.cjs` 39 条点击链全部通过，其中「电脑」一条覆盖备注的保存和清除。两个脚本均无页面报错。
