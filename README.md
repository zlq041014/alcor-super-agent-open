# 星引 Alcor · 智能体总管

星引把项目讨论、交给 Codex 或 DSH 的工作和结果集中在一个入口。Windows 端可单独使用；Android 端可连接配置好的 DeepSeek，也可与同一网络上的桌面端配对。

| 平台 | 本次公开范围 |
| --- | --- |
| Windows 0.2.1 | 首发基线。支持管理本机项目、规则和对话草稿，配置模型与执行端后可交接工作。 |
| Android 0.1.0 | 预览。包含本机文字记录、对话和同网配对入口；健康状态和接力结果以实际回执为准。 |

先在 Windows 启动并添加一个测试目录，就能试用项目、规则和草稿。使用模型需配置自己的 Key；真实执行还需要安装并登录相应的 Codex 或 DSH。默认没有预置任何账号和密钥。跨网接力以及更依赖具体设备或账户的功能不在首发验收范围。
