## Windows 0.2.1

- 核心流程：首次启动，添加本机测试项目，保存规则与对话草稿，重启后读取。验证不需要模型账户。
- 首发复验：Windows 构建、类型检查、43 项核心回归通过；Electron 实际启动并确认项目、规则和草稿可在重启后找回。
- DeepSeek、Codex 与 DSH 可自行配置。原生会话接力受登录、工具版本和原会话可用性影响，本次公开快照不重新验证真实账户。
- 桌面全量回归 210 项中 186 项通过、24 项失败，失败涉及自动推进循环、隔离执行、成果合入及相关恢复与用量记录。这些能力按预览处理，建议先在可恢复的测试项目中试用。
- [构建、使用和限制](../desktop-app/README.md)

- 源码小阶段：桌面派工确认检查执行端、模型目录版本、模型和思考强度。目录在确认期间变化，原输入和确认卡保留，不创建任务；重新选择后可确认。Windows 构建、类型检查、启动和 53 项回归通过；用隔离 Hub 复验两条界面路径。未调用正式模型，未改变普通讨论的模型路由。

- 源码小阶段：留用架可按版本保存内容、模板和经验。获准项目可以把模板复制到草稿进行编辑；经验只分享可复用的做法，出处原文留在维护视图。Windows 类型检查、构建、启动、3 项留用回归和 45 项发布回归通过；用隔离 Hub 验证了版本、授权范围和未确认不派工。Skill 尚未接入。

- 源码小阶段：留用架可从 Codex 的实际项目目录登记 Skill 来源并分享只读参考。可核对目标宿主是否报告同一来源，未授权项目不可读。星引只在选用时传递用户写的文字，不加载原 Skill；DSH 未提供目录。用真实 Codex 0.169.1 与隔离 Hub 验证界面，Windows 构建、类型检查、启动和 49 项回归通过。

- 源码小阶段：桌面项目出现并列决定时，可在规则页核对后确认一版；过期选择不改规则，历史验收仍按原版本可查。隔离 Hub 验证取消、并发变化和历史取证；Windows 构建、类型检查、启动与 59 项回归通过。

## Android 0.1.0 预览

- 从源码生成 Debug APK。包含本机笔记、对话、提醒和同网配对入口。预览中部分流程依赖设备权限，配对需有可访问的桌面端。
- 首发复验：Debug APK 构建、17 项 JVM 单测和模拟桥接的生产界面检查通过。未在本次快照上重做真机联调。
- 设计图与网页原型用于对齐界面，不能作为真机或跨网络验收。跨网接力、全部文件来源及真实账户的长时间使用不列入首发承诺。
- [构建、配置和验证](../mobile-app/README.md)

- 源码小阶段：带附件提问时，手机在上传或发送模型请求前核对本轮预算及材料可用性。拦截时保留原问题和已选材料，用户调整后再确认；不会自动发送。Android 16 用本机合成 HTTPS 验证超限零模型请求、重新打开、改选后只发所选附件。APK、JVM 单测、lint、原生检查与 WebView 回归通过；未发布安装包。

- 源码小阶段：手机可离线重开查看最近核实的共享项目要点和核实时间；项目换授权、重配或获知撤权后不能继续查看旧副本。个人备份不包含设备缓存。Android 16 和固定证书 Hub 实测断网重开、撤权后不复活及零派工。构建、JVM 单测、lint、原生检查与生产 WebView 回归通过。
